# FHIR essentials

A course for developers on the HL7® FHIR® standard: R4 with Swiss examples, the HTTP and JSON you actually send, the errors you get back and the traps to avoid. Each lesson prints on one or more A4 pages, and every fact is checked against the sources listed in the lesson's footer.

**Read it:** https://wheresvic.github.io/fhir-essentials/

## How it works

- The whole course is `index.html`: plain HTML and CSS, no build step, no JavaScript.
- To print, open the page in Chrome or Edge, choose A4 and turn off the browser's headers and footers; the page brings its own.
- A push to `main` republishes the page through GitHub Pages.
